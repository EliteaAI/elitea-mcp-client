ELITEA MCP Architecture

MCP client/server integration, external MCP sources, ELITEA APIs, and configuration services

Executive Summary

The ELITEA MCP repository is a protocol and integration layer. It connects MCP hosts and external MCP servers to ELITEA using MCP transports, REST, and Socket.IO.

MCP client/server

Provides CLI, tray, daemon, agent discovery, invocation, and external MCP connectivity.

Local persistence

Stores bootstrap and server settings in local config.json.

ELITEA platform

Provides application discovery, version metadata, prediction APIs, and Socket.IO MCP events.

Configuration subsystem

The server-side Configurations repository owns database-backed configuration services. MCP reaches it, if at all, indirectly through platform services.

Connection Paths

1. MCP host to ELITEA agents

MCP Host → server/mcp.py → Agent.predict() → ELITEA prediction API → MCP TextContent

Evidence: src/elitea_mcp/server/mcp.py, src/elitea_mcp/clients/elitea.py, and src/elitea_mcp/main.py.

2. MCP client to external MCP servers

config.json → commands/run_servers.py → server controller/session manager → external MCP server

Supported transports include stdio, SSE, and streamable HTTP. Evidence: src/elitea_mcp/commands/run_servers.py, src/elitea_mcp/utils/sio.py, and src/elitea_mcp/utils/session_manager.py.

3. MCP client to Socket.IO services

The bridge handles mcp_connect, mcp_tools_list, mcp_tools_call, mcp_notification, and mcp_ping. Evidence: src/elitea_mcp/utils/sio.py.

4. MCP client to local persistence

config.py stores deployment URL, token, project ID, server definitions, host, port, timeout, and SSL-related settings in a platform-specific config.json.

Evidence Status and Open Questions

Confirmed

  • MCP host connectivity through stdio and SSE.
  • ELITEA REST and Socket.IO integration.
  • External MCP connectivity through stdio, SSE, and HTTP.
  • Local config.json persistence.
  • MCP tool discovery and invocation.
  • Server-side configuration APIs and database-backed configuration models.

Indirect or inferred

  • The ELITEA agent runtime may resolve model/provider configuration through the Configurations subsystem.
  • MCP tool registrations may be persisted or managed by platform services outside the MCP repository.

Unresolved

  1. Which ELITEA service implements the server side of Socket.IO MCP events?
  2. Does the ELITEA prediction runtime always use EliteaAI/configurations?
  3. Are MCP tool registrations stored in the configuration database or another platform store?
  4. Which service backs each configuration endpoint used by other ELITEA clients?
